**Winchester Eagles Voleybal Club's Website**

# Introduction

This is the Winchester Eagles' Website. it is intended to be the main hub for the club's online presence, in pair with the official Instagram account.

Consult the project brief for more infomration about requirements, timeline and milestions. 

# Tech stack 

- NextJS
- React
- Typescript
- Tailwind Css
- React slick-carousel
- React icons

the webiste uses the new App folder routing systems. the Componenets folder group all reusable elements


# images naming convention

- location where the photo is found (i.e. home page teams, adults)
- what it is used for in that page
- identifier (i.e. 1, 2)

so for example:

"hpAdults1"  this is the first picture of the adults carousel situated in the home page

# Important documents naming convention

- use snake case 
- always begin the file name with capital club's initials "WEVC"
- where applicable end the file name with the year of creation i.e. 2025

NOTE: the file name as it is saved in the public folder is used as the name for the downloaded file in the user's machine hence the strict naming convention
